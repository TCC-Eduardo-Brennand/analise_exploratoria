# Exploratory Analysis of Formula 1 Data

This repository contains the code and resources for an exploratory data analysis (EDA) of Formula 1 races. The objective is to extract insights from historical race data, analyze key performance indicators, and identify trends that influence race outcomes.

## Description

The project focuses on the exploratory analysis of various race metrics, including:
- Lap times and consistency
- Pit stop strategies and their impact
- Tire compound performance
- Driver and team performance comparisons
- Weather conditions and their influence on races

## Technologies Used

- **Python 3.12.3**
- **Pandas** for data manipulation and analysis
- **NumPy** for numerical operations
- **Matplotlib & Seaborn** for data visualization
- **FastF1** for obtaining historical Formula 1 race data
- **Jupyter Notebook** for interactive data exploration
- **Poetry** for dependency management

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/TCC-Eduardo-Brennand/analise_exploratoria.git
   cd analise_exploratoria
   ```

2. Install dependencies using Poetry:
   ```bash
   poetry install
   ```

3. Activate the virtual environment:
   ```bash
   poetry shell
   ```

4. Open Jupyter Notebook to explore the data:
   ```bash
   jupyter notebook
   ```

5. Run the notebooks inside the `notebooks/` directory to visualize the analyses.

## Results

The exploratory analysis provides valuable insights into race dynamics, helping to understand how different factors impact race results. Visualizations and statistical summaries highlight key trends in Formula 1 strategy and performance.
